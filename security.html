Security

Designed around safer fitness data.

This page documents the production security direction for AIGYM’s account, data and deployment layers.

Account Protection

Validated login/signup fields, secure password handling in a production backend, session expiry and account recovery flows.

Least-Privilege Data

Connected health sources should request only the permissions required for the feature being used.

Transport & Storage

Production deployments should enforce HTTPS, secure cookies/tokens, encrypted secrets and server-side authorization.

Release QA

Website and WebApp repositories include automated QA workflows, while Mobile uses reproducible Android build workflows.
